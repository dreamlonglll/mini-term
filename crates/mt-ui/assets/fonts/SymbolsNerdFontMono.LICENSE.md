# Symbols Nerd Font Mono

`SymbolsNerdFontMono-Regular.ttf` is redistributed unmodified from the
[Nerd Fonts](https://github.com/ryanoasis/nerd-fonts) v3.5.1 release asset
`NerdFontsSymbolsOnly.zip`
(sha256 of the ttf: `fe471e538392f51910faab985fa8e192a39dd3426125edd15b71b3680df0e749`).

mini-term embeds it into the executable and uses it only to draw private-use-area
icons that the configured terminal font lacks (see `crates/mt-ui/src/terminal/symbols.rs`).
