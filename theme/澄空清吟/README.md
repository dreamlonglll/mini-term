# 澄空清吟

Mini-Term 独立浅色主题：冰白、晴蓝、银灰。
以清澈蓝天、白发和迎风白纱为画面核心，采用深蓝灰正文、晴蓝强调与浅冰蓝实底选区。
「澄空清吟」取澄净天空与清风低吟之意，突出清灵、通透的感觉。

## 导入

使用 Mini-Term 的外置皮肤导入功能选择 `澄空清吟.zip`，然后启用「澄空清吟」。
ZIP内只有一个同名中文目录，theme.json、background.jpg、README.md、manifest.json
均位于该目录顶层。显示名、theme.id、manifest.id、目录及ZIP名称一致。
其他已安装主题可继续保留。

## 图片与构图

- 图片来源：用户提供的 `【哲风壁纸】侧脸-氛围感-清冷.jpg`，4095×2160。
- 裁切框 `(320, 0, 3776, 2160)`，得到3456×2160的精确16:10画面。
- 等比例缩小为2560×1600，以质量93、无色度抽样的渐进式JPEG保存，不拉伸。
- 保留头顶发丝、脸部、蒙眼白纱和向右延展的飘带。
- 图片不调色，清淡氛围由原图及主题原生底色叠层形成；原始文件不修改。
- `focusX=0.5`、`focusY=0.45` 是其他窗口比例下的cover百分比定位，不是人物坐标。
- 图片作者和再分发许可无法仅从本地文件确认，图片权利归原权利人。

## 配色与效果

- 冰白背景 `#f0f6fa`、雾蓝灰面板、深蓝灰正文 `#23364b`。
- 主强调色 `#246087` 为适合浅底阅读的沉稳晴蓝，辅以低饱和蓝紫。
- 警告用暖琥珀、成功用松绿、错误用柔和绯红，维持语义区分。
- 晴蓝光标配冰白光标文字；浅冰蓝实底选区配深蓝灰文字。
- `backgroundDim=0.10`：以冰白底色轻铺图片，保留原有的蓝天色调。
- `terminalOpacity=0.84`：让白纱和天空适度透出，同时提供稳定的正文阅读底层。
- `surfaceOpacity=0.92`：侧栏等面板使用较实的雾蓝灰底层，减轻飘带纹理对列表的干扰。
- 配齐ANSI 16色；bright槽位也采用适合浅色底层的颜色，brightWhite与正文同色。
- 使用theme.json原生字段，不附加CSS或tokens，不设置被带图模式忽略的terminal.background。

## 检查范围

对包内JPEG的每个像素按配置合成背景遮罩及终端、面板底层，检查静态文字对比度：
正文至少7:1，辅助及语义文字、ANSI 16色和两种面板上的语义文字至少4.5:1，
光标文字至少4.5:1，选区文字至少7:1。
检查不覆盖程序自定义真彩色、变暗、反色输出或TUI自带背景。
这些计算是静态合成模型，不是实际应用像素的测量。

同时检查JSON、字段和数值范围、UTF-8文件名、图片解码及尺寸、ZIP CRC，
以及manifest列出的文件大小与SHA-256。manifest记录theme.json、background.jpg及README.md，
修改这些文件后需要重新生成清单。
改名前的配色版本已由用户截图确认显示；本次仅改名，图片、配色和效果参数不变。
项目中的预览为配色合成示意，不是应用截图。
