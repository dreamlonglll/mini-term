# 暮紫鎏金

Mini-Term 深色幻想主题：深梅紫底色、香槟金强调、柔白文字，以及沉入暮色的粉金云海。
银发精灵、金色长笛与白色石柱使用原图呈现，色彩氛围通过应用的背景底层叠加形成。

## 导入

使用 Mini-Term 的外置皮肤导入功能选择 `暮紫鎏金.zip`，然后启用「暮紫鎏金」。
压缩包内有一个同名目录，theme.json、background.jpg、README.md、manifest.json
均位于该目录顶层。本主题是独立包，可与「暮霞云歌」浅色主题同时保留。

## 构图

- 图片来源：用户提供的 `云端-吹笛-天空.jpg`，3842×2160。
- 裁切框：`(116, 0, 3572, 2160)`，裁成3456×2160后等比缩小至2560×1600。
- 背景为16:10渐进式JPEG；不拉伸，不改变原图色调，原始文件保持不变。
- 向左取景保留吹笛人物、完整长笛与石柱，同时保留右侧霞光和云海。
- `focusX=0.36`、`focusY=0.5` 用于其他窗口比例下的cover百分比定位，不是人物坐标。
- 图片作者及再分发许可无法仅从本地文件确认；图片权利归原权利人。

## 风格与效果

- 深梅紫背景，逐级抬升的紫灰面板，细玫瑰紫边框。
- 香槟金主强调、杏粉提示、雾蓝信息、浅松绿成功。
- 柔白正文、淡玫瑰灰次要文字，避免暗底上的说明文字过暗。
- 完整ANSI 16色、金色光标、梅紫实底选区。
- `backgroundDim=0.26`：使用深梅紫底色让霞光柔和下来。
- `terminalOpacity=0.72`：保留云海和人物轮廓，给文字提供稳定的暗色底层。
- `surfaceOpacity=0.80`：提高侧栏等面板的稳定程度。
- 颜色与效果使用theme.json原生字段，不附带CSS或tokens。

## 校验范围

进行JSON、字段范围、图片解码和尺寸、UTF-8文件名、ZIP CRC、manifest文件大小
与SHA-256检查。静态配色检查依据配置的背景底色遮罩与终端底层，对包内JPEG的
每个像素计算对比度，并检查两种面板、光标文字和选区文字。

正文静态对比度要求至少7:1，次要文字及语义强调色要求至少4.5:1。
ANSI 16色中，black保留为接近底色的真正黑色槽位，不保证黑字在暗底上可读；
其余15色（包括brightBlack）均按至少4.5:1检查。
检查不覆盖程序自定义真彩色、反色、变暗文字或自带背景的TUI。

manifest.json记录theme.json、background.jpg及README.md的字节数与SHA-256，
修改这些文件后应重新生成清单。
