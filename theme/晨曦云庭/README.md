# 晨曦云庭

Mini-Term 浅色幻想主题：晨曦蓝紫天空、云海倒影、浮空圣城与白发精灵。

## 导入

在 Mini-Term 的设置 → 外观 → 主题与语言 → 外置皮肤中，
选择「导入 zip」并选中 晨曦云庭.zip，再启用「晨曦云庭」。
也可用「添加皮肤」选择解压后的 晨曦云庭 文件夹。

## 图片与构图

- 来源文件：用户提供的 `二次元-云朵-天空.jpg`（3840×2160）。
- 包内图片：2560×1600，16:10，渐进式 JPEG。
- 由原图裁取约 `(154, 0)–(3610, 2160)`，再等比例缩小，没有拉伸。
- 取景向左保留白发精灵、白鸽和钟表平台，同时保留右侧浮空圣城。
- `focusX=0.40`、`focusY=0.5`，用于应用在其他窗口比例下的 cover 定位。
- 原图作者及再分发许可未在本地文件中确认；图片权利归原权利人。

## 配色与效果

- 明暗模式：浅色。
- 界面：云白底色、蓝紫面板、靛紫强调、深蓝正文。
- 状态色：蓝色信息、青绿色成功、暖金色提示、酒红色错误。
- 终端：完整 ANSI 16 色、光标和选区颜色。
- `backgroundDim=0.18`：轻微压低天空和云海高光。
- `terminalOpacity=0.88`：为终端内容提供稳定的浅色阅读底。
- `surfaceOpacity=0.92`：加实侧栏等面板底层，减弱云海与人物线条对列表的干扰。
- 蓝灰辅助字色调整为 `#4d5576`，青绿色界面语义色调整为 `#206155`，补强较深面板上的文字对比。

本轮精修保留原图、构图、正文颜色、终端ANSI配色、选区、背景遮罩和终端不透明度。
对包内JPEG全部像素检查两种面板上的正文、辅助及语义字色，目标至少4.5:1。
本包使用 theme.json 中的颜色与效果字段，不附加 `theme.css` 或 `tokens`。

## 文件与校验

theme.json、background.jpg 和 README.md 均位于 晨曦云庭 目录顶层。
manifest.json 记录上述三个文件的字节数和 SHA-256。
修改任何被记录的文件后，应重新生成清单并重新打包。

本包经过 JSON、字段、图片解码、SHA-256 和 ZIP 完整性静态检查，
以及终端和两种面板的静态文字对比度检查。
初版已由用户截图确认在Mini-Term中显示；本轮侧栏精修尚未确认导入后的实际效果。
预览图是依照配置合成的示意图，实际界面以应用渲染为准。
