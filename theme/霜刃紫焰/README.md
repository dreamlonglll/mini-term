# 霜刃紫焰

Mini-Term 独立深色主题：深蓝黑打底、冰蓝为主、紫焰为辅。
以银发少女、横向蓝色刀光和右上紫焰为画面核心，界面采用冷白正文、冰蓝强调，
搭配淡紫辅助提示、紫色选区和冰蓝光标。原有「银灰机能」等主题保持不变。

## 导入

使用 Mini-Term 的外置皮肤导入功能选择 `霜刃紫焰.zip`，然后启用「霜刃紫焰」。
ZIP内只有一个同名中文目录，theme.json、background.jpg、README.md、manifest.json
均位于该目录顶层，主题显示名、id和目录名一致。

## 图片与构图

- 图片来自用户提供的 `【哲风壁纸】伊蕾娜-战斗-紫焰.jpg`，原始尺寸4992×2816。
- 裁切框 `(248, 3, 4744, 2813)`，得到4496×2810的精确16:10画面。
- 等比例缩小为2560×1600，JPEG质量93，保留较清晰的人物线条与刀光，不拉伸。
- 保留双眼、横贯画面的刀光和右上紫焰；与银灰机能使用相同构图和相同JPEG。
- 原图及包内壁纸不进行调色；深色氛围由主题的原生底色叠层形成。
- `focusX=0.5`、`focusY=0.45` 是其他窗口比例下的cover百分比定位，不是人物坐标。
- 原始图片文件保持不变。图片作者和再分发许可无法仅从本地文件确认，权利归原权利人。

## 配色与效果

- 深蓝黑背景 `#101827`，蓝灰面板，冷白正文，低饱和蓝灰次要文字。
- 主强调为冰蓝 `#75d9ff`，淡紫 `#cbb0f7` 用于辅助提示。
- 成功信息用浅松绿，警告用柔和琥珀，错误用淡绯红，保持语义区分。
- 冰蓝光标配深色光标文字，紫色实底选区配冷白文字。
- `backgroundDim=0.28`：以深蓝黑底色压低原图大面积白色背景的亮度。
- `terminalOpacity=0.74`：保留刀光和紫焰，减轻人物线条与终端文字的竞争。
- `surfaceOpacity=0.86`：让侧栏等面板有更稳定的蓝灰底层。
- 使用theme.json原生颜色、图片和效果字段，不附加CSS或tokens，不配置被带图模式忽略的terminal.background。

## 终端颜色与检查

配齐ANSI 16色、前景、光标和选区。
对包内JPEG每一个像素按配置叠加背景遮罩及终端/面板底层，计算静态文字对比度：
正文至少7:1；次要文字、语义强调及除black外的15种ANSI颜色至少4.5:1；
两种面板上的语义文字至少4.5:1；光标文字和选区文字至少7:1。

ANSI black保留传统深蓝黑色，便于程序用作背景或色块；它在深色底上作为文字时
不保证清晰，是上述ANSI文字对比度检查的明确例外。brightBlack已提亮为可读蓝灰色。
静态检查不覆盖程序自定义真彩色、反色、变暗文字或TUI自带背景。

检查包含严格JSON、字段及数值范围、UTF-8文件名、图片解码、尺寸、ZIP CRC，
以及manifest列出的三个文件的字节数与SHA-256。更改文件后应重新生成manifest。
项目中的预览为配色合成示意，不是应用截图；本主题尚未确认导入后的实际显示效果。
