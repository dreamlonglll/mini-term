# 霜蓝听雪

Mini-Term 独立柔和深色主题：深雾蓝、银白、冰蓝。
以银蓝长发、蒙眼饰带和右侧冷白高光为画面核心，营造清冷、安静的氛围。
界面采用蓝灰面板、银白正文、冰蓝强调与光标，搭配蓝灰实底选区。

## 导入

使用 Mini-Term 的外置皮肤导入功能选择 `霜蓝听雪.zip`，然后启用「霜蓝听雪」。
ZIP内只有一个同名中文目录，theme.json、background.jpg、README.md、manifest.json
均位于该目录顶层，显示名、id、目录及ZIP名称一致。可与原有主题同时保留。

## 图片与构图

- 图片来自用户提供的 `【哲风壁纸】AI-二次元.jpg`，原始尺寸3840×2160。
- 裁切框 `(256, 0, 3712, 2160)`，得到3456×2160的精确16:10画面。
- 等比例缩小为2560×1600，以质量93、无色度抽样的渐进式JPEG保存，不拉伸。
- 略向右取景，保留完整脸部、饰带和右侧发丝高光，同时保留左侧长发延展。
- 原图及包内壁纸不调色；深色氛围由主题原生底色叠层形成。
- `focusX=0.65`、`focusY=0.45` 是其他窗口比例下的cover百分比定位，不是人物坐标；窄窗口适度偏向右侧取景。
- 原始图片文件保持不变。图片作者和再分发许可无法仅从本地文件确认，权利归原权利人。

## 配色与效果

- 深雾蓝背景 `#17273a`，蓝灰面板，银白正文 `#e5eef8`，浅蓝灰辅助文字。
- 主强调为冰蓝 `#9bd8f4`，辅以少量淡灰紫。
- 成功用浅松绿，警告用柔和琥珀，错误用灰玫瑰，保持语义区分。
- 冰蓝光标配深色光标文字，蓝灰实底选区配银白文字。
- `backgroundDim=0.22`：以深雾蓝底色压低面部和发丝高光，保留原图蓝色层次。
- `terminalOpacity=0.78`：降低密集发丝与文字的竞争，让银白正文在高光区域也能清楚显示。
- `surfaceOpacity=0.90`：让侧栏等面板有更稳定的蓝灰底层。
- 使用theme.json原生颜色、图片和效果字段，不附加CSS或tokens，不配置被带图模式忽略的terminal.background。

## 终端颜色与检查

配齐ANSI 16色、前景、光标和选区。
对包内JPEG每一个像素按配置合成背景遮罩及终端、面板底层，计算静态文字对比度：
正文至少7:1；辅助、语义文字及除black外的15种ANSI颜色至少4.5:1；
两种面板上的语义文字至少4.5:1；光标文字和选区文字至少7:1。

ANSI black保留传统深雾蓝色，便于程序用作背景或色块；它在深色底上作为文字时
不保证清晰，是上述ANSI文字对比度检查的明确例外。brightBlack已提亮为可读蓝灰色。
静态模型不覆盖程序自定义真彩色、反色、变暗文字或TUI自带背景，亦不是应用像素的实测。

检查包含严格JSON、字段及数值范围、UTF-8文件名、图片解码、尺寸、ZIP CRC，
以及manifest列出的三个文件的字节数与SHA-256。更改文件后应重新生成manifest。
项目中的预览为配色合成示意，不是应用截图；尚未确认导入后的实际显示效果。
