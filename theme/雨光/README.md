# 雨光

Mini-Term 深色壁纸主题：深蓝灰面板、冷青色强调、暖金色提示。

## 导入

在 Mini-Term 的设置 → 外观 → 主题与语言 → 外置皮肤中，
选择「导入 zip」并选中 雨光.zip，再启用「雨光」。
也可用「添加皮肤」选择解压后的 雨光 文件夹。

## 图片与构图

- 来源：用户提供的 wallhaven-72o6ze.jpg（3840×2160）。
- 包内图片：2560×1600，16:10，渐进式 JPEG。
- 先从原图裁取 (320, 0)–(3776, 2160)，再等比例缩小；没有拉伸。
- 多保留右侧人物与雨伞，原始图片保持不变。
- focusX=0.72、focusY=0.5，在较窄窗口中优先保留偏右构图。
- 原画作者及许可未在本地文件中确认；图片权利归原权利人。

## 配色与效果

- 界面：十个语义色；终端：完整 ANSI 16 色、光标与选区颜色。
- backgroundDim=0.34：背景压暗浓度。
- terminalOpacity=0.70：终端底色不透明度。
- surfaceOpacity=0.78：侧栏等面板不透明度。

调小 terminalOpacity 会让壁纸更明显，调大会使文字背景更稳定。
如需先尝试更强的壁纸氛围，可把它改为 0.60；随后检查明亮灯牌区域的文字。
本包使用 theme.json 中的颜色与效果字段，不附加 theme.css 或 tokens。

## 文件与校验

theme.json、background.jpg 和 README.md 均位于 雨光 目录顶层。
manifest.json 记录上述三个文件的字节数和 SHA-256。
修改任何被记录的文件后，应重新生成清单并重新打包。
压缩包内部保留 雨光/ 目录，使目录名与主题 id 一致。

本包经过 JSON、字段、图片解码、SHA-256 和 ZIP 完整性静态检查，
尚未在 Mini-Term 内进行导入或渲染验收。
预览图是依照配置合成的示意图，实际界面以应用渲染为准。
