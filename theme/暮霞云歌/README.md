# 暮霞云歌

Mini-Term 浅色幻想主题。银发精灵在云端吹奏金色长笛，粉金霞光映照白色石柱与云海。
以象牙白、玫瑰紫和沉稳暖金衔接原图色彩，保留背景氛围并照顾文字阅读。

## 导入

在 Mini-Term 的外置皮肤导入功能中选择 `暮霞云歌.zip`，导入后启用「暮霞云歌」。
压缩包内只有一个同名目录，theme.json、background.jpg、README.md 和 manifest.json
均位于该目录的顶层；无需单独导入图片。

## 图片和构图

- 来源：用户提供的 `云端-吹笛-天空.jpg`，3842×2160。
- 背景：2560×1600，16:10，渐进式 JPEG。
- 原图裁切框：`(116, 0, 3572, 2160)`，裁切尺寸3456×2160，再等比例缩小。
- 构图向左保留人物、长笛与白色石柱，右侧保留粉金霞光与云海。
- 不拉伸、不改变原图色调；原始文件保持不变。
- `focusX=0.36`、`focusY=0.5` 是其他窗口比例下的 cover 百分比定位，不是人物坐标。
- 图片作者及再分发许可无法仅从本地文件确认，图片权利归原权利人。

## 配色和效果

- 浅色外观：象牙白底色、淡玫瑰面板、深灰紫正文、玫瑰紫主强调色。
- 暖金用于提示，灰蓝用于信息，松绿用于成功，莓红用于错误。
- 完整 ANSI 16 色；浅色主题的 bright 槽位也使用有足够对比度的颜色，
  brightWhite 与正文一致，避免加粗输出变成难以辨认的白字。
- `backgroundDim=0.10`：以主题底色轻铺背景，保持霞光原有的暖色。
- `terminalOpacity=0.78`：在背景可见程度与文字清晰度之间取平衡。
- `surfaceOpacity=0.90`：加实侧栏等面板底层，减轻人物头发、衣服和建筑线条对文件列表的干扰，弹出层实际效果由应用决定。
- 本轮仅调整面板不透明度；原图、构图、全部配色、光标、选区及正文区底层均保持原样。
- 光标为玫瑰紫；选区为浅玫瑰色实底，选区文字为深灰紫。
- 使用 theme.json 的原生颜色、背景和效果字段，不附加 CSS 或 tokens。

## 检查范围

本包进行 JSON 和字段检查、图片解码、文件大小和 SHA-256 清单核验、ZIP CRC 检查。
制作过程还依照背景底色遮罩与终端底层的合成顺序，对包内 JPEG 的每一个像素
检查正文、次要文字、强调色及 ANSI 16 色的静态对比度，并检查两种面板底层。
这些检查不覆盖程序自定义真彩色、反色、变暗输出或自带背景的 TUI。

`manifest.json` 记录 theme.json、background.jpg 和 README.md 的字节数与 SHA-256；
修改这些文件后必须重新生成清单。

初版已由用户截图确认在Mini-Term中显示；本轮侧栏精修尚未确认导入后的实际效果。
项目中的预览图为根据配置制作的配色示意，不是应用截图；实际界面以 Mini-Term 为准。
