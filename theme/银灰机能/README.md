# 银灰机能

Mini-Term 浅色主题：银白底色、石墨灰文字、冰蓝选区与冷蓝强调。
以黑白漫画式人物线条为背景，保留原图蓝色刀光和紫焰，界面本身保持干净、克制。

## 导入

使用 Mini-Term 的外置皮肤导入功能选择 `银灰机能.zip`，然后启用「银灰机能」。
包内只有一个同名目录，theme.json、background.jpg、README.md 和 manifest.json
均位于该目录顶层。本包为独立主题，可与其他皮肤同时保留。

## 图片与构图

- 图片来源：用户提供的 `【哲风壁纸】伊蕾娜-战斗-紫焰.jpg`，4992×2816。
- 裁切框：`(248, 3, 4744, 2813)`，裁切尺寸4496×2810，精确16:10。
- 等比例缩小至2560×1600，以渐进式JPEG保存，不拉伸。
- 居中保留人物双眼、横向刀光和右侧紫焰。
- 不改变原图色调；原始文件保持不变。
- `focusX=0.5`、`focusY=0.45` 为其他窗口比例下的cover百分比定位，不是人物坐标。
- 图片作者及再分发许可无法仅从本地文件确认；图片权利归原权利人。

## 配色与效果

- 银白背景，银灰面板，浅冰蓝抬升面板和选区，石墨灰正文。
- 冷蓝作为主强调，红、绿、琥珀和紫色主要用于终端语义区分。
- 文字用较深的冷蓝与蓝灰，避免亮冰蓝文字在浅色背景上难以辨认。
- 配齐ANSI 16色、冷蓝光标和浅冰蓝实底选区。
- brightWhite与正文同色，保证加粗或明亮前景仍适合浅色底层。
- `backgroundDim=0.12`：以主题银白底色轻铺原图。
- `terminalOpacity=0.88`：进一步减淡阅读区内的人物和刀光，保留漫画轮廓并减少文字干扰。
- `surfaceOpacity=0.92`：加实侧栏等面板的银灰底层，让项目与文件列表的阅读底色更稳定。
- 使用theme.json原生背景、颜色和效果字段，不附加CSS或tokens。

## 校验范围

进行JSON与字段范围检查、UTF-8文件名检查、图片解码与尺寸检查、ZIP CRC检查，
并核对manifest记录的文件大小及SHA-256。
静态对比度检查使用包内JPEG的每一个像素，按配置的背景底色遮罩与终端底层合成，
检查正文、次要文字、语义强调色、ANSI 16色、两种面板、光标文字与选区文字。
正文要求至少7:1；ANSI 16色和语义文字要求至少4.5:1。
这些计算不覆盖程序自定义真彩色、反色、变暗文字或自带背景的TUI。

manifest.json记录theme.json、background.jpg及README.md的字节数与SHA-256；
修改这些文件后需要重新生成清单。
初版已通过用户提供的Mini-Term实机截图确认加载；本次底层不透明度调整版尚未实机复核。
项目中的预览为配色合成示意，不是应用截图。
